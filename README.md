# The A+ Team: A Chemistry Getaway

A browser game (three.js) for Introduction to Chemistry. Drive the van through three legs of checkpoints (stoichiometry, solutions, molecular geometry), then fly the helicopter through a gas-law finale. Five questions per leg, each with a hint and an explanation.

Play: https://neogio73.github.io/a-plus-team/

Files
- `index.html` — the game
- `van.json` — the van model (packed glTF)
- `theme.mp3` — title music
